# Jinky

Jogue os jogos do PC na TV (Google TV e Fire TV).

Este repositório guarda só os **instaladores** do Jinky para Windows. O app instalado verifica atualizações aqui sozinho.

**Para instalar:** baixe o `Jinky-Setup-<versão>.exe` mais recente em [Releases](https://github.com/poncianomateus/jinky-releases/releases).

O arquivo `.sha256` ao lado de cada instalador é usado pelo Jinky para conferir que o download está íntegro.
